# 凯风餐厅建模证据

本轮核对日期：2026-11-04。仅改善独立模型；没有从照片提取发布纹理，也没有将历史外观或程序交互称为当前经营状态。

## 采用的照片与资料

- [深圳大学本科招生《遇见美食｜等正式开学后，我要吃遍深大！》](https://www.sohu.com/a/382521779_675908)，2020-03-23。文章明确写明凯风餐厅即新西南餐厅、靠近小西门。外景照片能辨认浅色小瓷砖、深绿色玻璃、黄色大墙框、红色楼梯背墙、白色外框，以及外廊和楼梯的细密金属竖杆。已有离线照片：`build/campus-references/southwest-canteens/new2020.jpg`。本轮仅据此细化杆件和外廊楼板，不把相机透视推成实测尺寸。
- [2019 年公开校园介绍及照片](https://www.sohu.com/a/334861049_239689)，2019-08-19。已有离线照片：`build/campus-references/southwest-canteens/new2019.jpg`。照片可辨入口红色雨棚、外墙瓷砖、窗格、墙旁座位与一侧白色百叶构件。红雨棚已被较晚照片取代；百叶所在侧翼尚不足以准确配准，因此本轮不把它随意加到主正面。
- [《深大宿舍内部图可以看啦，新生都会住哪里啊？『深大荔知』》](https://www.sohu.com/a/711812442_121117481)，2023-08-14。该文称其现场拍摄，且自身声明是目测资料，不保证后续现状。新西南餐厅段的[入口照片](https://p2.itc.cn/q_70/images03/20230815/b3775ee62c18472c89291d9df2899da6.jpeg)清楚显示：浅色横牌写有“凯风餐厅”和“KAI FENG CANTEEN”，入口两侧为绿色金属分格玻璃，较早照片的红色商业雨棚已不见。离线观察件：`build/kaifeng-reference/student-2023-front.jpeg`。程序使用系统字库重新排字，再生成现有红色网格层内的字形几何；未复制照片、水印、海报或经营广告。
- 同一文章的[室内照片](https://p2.itc.cn/q_70/images03/20230815/505a44869fcf4bc3950885282cf027a8.jpeg)，离线件 `build/kaifeng-reference/student-2023-side.jpeg`，可见售餐窗口和梁柱，但不足以与完整建筑平面配准；本轮不据此扩建内部模型。

## 本轮具体改进与估计边界

1. 入口由旧红雨棚改为2023年照片可见的浅色横向餐厅名牌；入口玻璃与门扇比例随近照修正。门宽2.4米、门高2.35米、横牌4.8×1.10米均是视觉估计，不是照片标注的尺寸。入口中心、建筑轮廓和14.4米总高沿用原模型，未重新宣称已验证。
2. 依据外廊可见的细竖杆与浅色楼板，补齐上层外廊楼板，并用较细、较密的杆件代替原来约1.15米间隔的稀疏立杆。1.05米栏杆高、0.18米竖杆间距和杆径均为近似。
3. 在原楼梯与外廊范围内补转向平台、留出护栏通行口，并让最后踏步与3.55米外廊同高。原模型顶步低0.20米、斜扶手底端接近地面、外廊栏杆横挡楼梯出口，属于程序几何连接问题；修正连接不代表测得现场标高。18个踏面、0.58米踏面进深及整段定位仍沿用估计。
4. 不增加楼层、不更改校园地形，不声称复刻现时广告、门禁、室内完整布局或坡道。门扇开合保留为课程交互演示。

全部输出文件及 `make_kaifeng` 调用接口保持不变。纹理仍为程序绘制，照片仅供观察。
