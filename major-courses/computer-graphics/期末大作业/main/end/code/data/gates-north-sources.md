# 立功、立心、立言门的建模依据

本文件对应 `campus_gates_north.py` 与 `gates-north.json`。每门、每种材质单独生成网格，位置沿用项目离线地图坐标。外部照片只用于观察，没有复制进运行素材；文字、色块和圆形徽记由程序及本机字体重绘。所有尺寸、层高和设施数量都是照片近似，不能作为现场测量或实时通行信息。

## 立功门

- 校门定位采用项目 OSM `node/2400176747`（深圳大学北门，约 x=286.07,z=-688.53），附近为 `way/222088986` 北门路、`way/222088987` 回转线和 `way/231676385` 环校道路。
- 2020 年迎新文章明确标注“立功门外”，图片可见圆弧玻璃岗亭、浅色下墙、深色金属框、银色闸机和扶栏：<https://www.sohu.com/a/418822058_168313>。项目已有研究图 `build/campus-research-reference/legong-2020-1.jpg`，本次重新查看确认上述形态。
- 模型将玻璃弧面、横向边框、竖向细框、屋檐、低墙、门把手、闸机和扶栏分层；沿用旧模型估计的岗亭中心 `(300.8,-678)`，处在北门主车道东侧。
- 当前未找到足以确认该岗亭全平面和精确直径的资料，完整圆形平面、直径约 5.9 米、3.27 米檐顶等都是近似。2020 年迎新照片中的临时帐篷未作为永久设施。闸机短臂收向侧边以保留可探索的净空，并不表达真实开闭状态。
- 外国语学院图库另有双弧形岗亭和上方镂空连桥的旧照片 `sfl-gate2.jpg`，但图片未标明门别；本次不把无法确认的连桥结构套用到立功门。

## 立心门

- 用户提供的 2023 年粤海校区校园地图将立心门标在田径场东北侧、靠近深大站 C 口的一侧。项目 OSM `way/239834465` 从校园内 `(581.8,-553.4)` 经 `(611.3,-522.9)` 到校界 `(630.2,-508.7)`，随后 `way/239872139` 台阶接入外侧 `way/764380662` 人行道。模型门区中心暂取该校界接点，仍需门牌或测绘进一步确认。
- 校方 2014 年研究生迎新通知将小东门和科技南一路、深大站 C 出口联系起来：<https://yz.szu.edu.cn/info/1041/10262.htm>。该资料用于地理关系，不能证明门区当前外貌或开放状态。
- 高德“小东门” POI：<https://ditu.amap.com/place/B0J0TAUA55>，页面坐标为 GCJ-02 `113.942573,22.537020`。转换 WGS-84 后大致落在 `(606,-505)` 一带，只用来核对入口区域；没有直接用这个点定位塔体或当成精确测量。
- “深大淘课”于 2023 年 6 月 12 日发布“小东门开通”的同组实拍，公开备份见：<https://peachring.com/u/2505699604-%E6%B7%B1%E5%A4%A7%E6%B7%98%E8%AF%BE/>。其显示的旧开放时间只属于当时信息，模型不显示该时间。

- 照片支持入口外观组成，不能独立确定其精确朝向、塔体尺寸、内部平面或上下平台高程。模型踏步以不大于约 0.18 米级高接回当前估计地形，藤棚通廊长约 7.2 米并逐段贴近地面。当前示意由道路侧入口向校内下降，不能据此断言这是照片中真实楼梯的升降方向或楼层关系；方向和标高仍需现场校准。未将通廊内端悬空在粗地形上。

- 电梯只表现关闭门扇和框体，未实现电梯运动；圆形徽记使用 SZU 与校名字体示意，并非原校徽。藤叶、栏杆网格和钢管的密度及尺寸为近似。输出额外 `campus-gate-lixin-walk.mesh`，包含入口踏步、前场、内部台阶及通廊上表面，供根生成器接入贴地步行高度。

## 立言门

- 学校 2024 年“冷原子多体量子物理与量子精密测量”讲习班交通指南第 60 页明确以“深大校门-立言门”标注入口照片：<https://quantum.szu.edu.cn/__local/9/EE/EF/8917DF4C32A20BC1C17091640B2_DE1E0D7E_1C3170.pdf>。已查看项目保存的 `liyan-guide-source-212.jpeg` 及 `liyan-photo-crop.png`。
- 照片可见中央岗亭、两侧黄黑分流岛、蓝色设备、高杆及上方召南桥。门区定位沿用 OSM `way/231085451` 和旧模型中心 `(137,337)`；原有召南桥继续由桥梁模型绘制，本模块没有重复搭建横跨道路的门楼。
- 新网格分别表现岗亭基座、玻璃窗、金属分格、薄屋檐、分流岛、设备箱及高杆。道闸竖起以保留预览通路，实际开放情况尚未核实。
- 岛数、岛宽、设备尺寸、蓝色牌面内容和杆件位置均按照片近似。标识文字为程序重绘的概括，不能当成照片原牌的逐字复刻。

## 集成与替换

- 在 `generate_campus.py` 生成地形后调用 `make_gates(...)`。函数只写传入 `assets` 目录中的独立网格及三张 PPM；返回门别、相机、分层、颜色和估计说明。
- 运行时停止调用 `main.cpp` 中旧的 `legongGate(...)` 与 `liyanGate(...)`，避免新旧岗亭和门禁重叠。旧的 `lideGate(...)`、`zhiyuanGate(...)` 已分别由西侧、南侧门区模块替换，同样停止旧调用；召南桥及北门棕榈继续保留。
- 立心门没有旧的专用门区函数可替换。含接地过渡的最大平面范围约为 `x=611.3..635.9,z=-523.4..-502.8`；附近随机树木由统一生成器避让，本模块不直接改动全校植被。
- 独立开发阶段使用当前地形、现有 `MeshWriter/beam/extrude` 在研究目录试生成，核对网格头、有限坐标、材质层、文字纹理和全宽步行网格。该检查不作 GUI 画面验收结论；最终集成画面和通行由根代理统一验证。
