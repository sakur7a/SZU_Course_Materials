# 周南桥—斋区出口与沿路地标

用户确认，从周南桥人行层往斋区需上楼梯。出楼梯后沿路可到紫薇斋菜鸟驿站、中国银行和信息中心。用户已指认现场图组的首张照片为对应的下层出口，并确认上层道路尚未开放，要求本轮跳过上层。早期桥端试验保存在 build/zhounan-north-pilot，挡门试验保存在 build/zhounan-gate-pilot，两者都未同步到常用预览。

## 可用于对照的照片

- [周南桥 2024 年现场图组](https://www.sohu.com/a/815722961_121117481)：用户指认开头第一张。可见下层人行面从桥侧进入粉砖转向平台，平台外缘的竖杆栏杆转折，另一侧靠浅灰墙和树池。照片只显示部分上行方向及当时的临时围栏，外端路缘、总级数和标高仍待复核。
- [深大校报斋区外景图组](https://www.sohu.com/a/747816124_121124028)：斋区段落的第二张照片可读到“聚翰斋”楼名，同时拍到外部宽台阶、深色墙面和连续玻璃，供首层体量参考。该组照片未标出中行或信息中心的外门。另有[荔知的斋区宿舍实拍](https://www.sohu.com/a/710071423_121117481)，可对照新斋区各塔楼和底层关系。
- [紫薇斋菜鸟驿站照片和快递地址](https://www.sohu.com/a/802902438_121117481)：粤海校区一栏是取件区室内照片和楼宇示意地图，未显示临街门头。
- [中国银行官方网点](https://www.boc.cn/sourcedb/operations2021/406/678/681/index_124_6.htm)列聚翰斋半地下一层 B103。[深圳大学新生联系资料](https://zs.szu.edu.cn/__local/4/F1/FC/A0451720CB15609CF09595BF39A_435A5DEA_F1004.pdf)将信息中心服务大厅定位到聚翰斋环校道路面。[信息中心联络页](https://www1.szu.edu.cn/nc/view.asp?id=177)也把两项服务列在同楼。2021 年[商铺图组](https://www.sohu.com/a/484887677_121117481)拍到的是汇紫楼旧地址，不能用于确定聚翰斋门面。

## 与现有底图的对应

- [学校校园地图](https://www.szu.edu.cn/xxgk/xydt.htm)和本地 OSM 的紫薇斋（way/1558576825）及聚翰斋（way/1558576826）可提供楼栋锚点。沿深大东路（way/488453361）中心线，从 OSM 楼梯候选出口向北到两栋楼中心投影约为 117 米、184 米。数字只代表地图投影，不是门到门的实走距离。
- OSM 的楼梯候选 way/984608622 与桥下人行线 way/776358646 及地面人行道 way/1282922809 分别共用节点。步道链经 way/1282922810、way/1282922811 往北，北段和两栋楼分列深大东路两侧。需要校准如何接到楼侧，不能把这条沿路步道直接画进门面。另有贴近楼栋的内侧道路 way/971088921，可作为候选，不代表已经确认顾客入口所在侧。
- 本地 OSM 的中国银行节点 2453780718 在聚翰斋以西约 400 米，不能拿作聚翰斋网点落点。楼内服务位置和外部门洞坐标分开记录。
- 桥北端 way/611264729 是上层桥板与深大东路之间的短接线。带斑马线标记的节点 11904646197 同时属于该短接线和人行横道 way/1282922810，横道跨的是短接线。2024 年图组分别从路侧和桥上拍到横向挡门、限高架及门外斑马线。按用户反馈，斋区更新只处理下层人行入口与出入口外的步行衔接。
- 隔离试验里移动梯轴、下挖地面、七级踏步和端部墙体都是场景拟合，均没有纳入现状标注。南区中段楼梯 way/776358647 与斋区出口分别核对。

下层照片样板在 build/zhounan-lower-photo-study。校园版按样板中的人行板、侧向粉砖平台、折线竖栏和浅灰侧墙重建，在现有地形中接入斋区人行道。踏步临车道侧收窄，桥下局部地形降至平台以下。程序验证了踏面无地形穿插、楼梯可双向行走，以及上层车道路面和标线资源与原版逐字节相同。七级、1.05 米总高差、墙体和边坡为现场照片与地图的拟合值。上行末端到沿路门面之间的连续实景仍待补充。

沿深大东路往聚翰斋方向，OSM 还有一处独立台阶 way/239872944。地图线端接到道路中心节点，2013 年的标注早于新斋重建。旧模型约有 3.4 米踏步伸入车道。现用地面台阶模块按车行面裁切，两端接入已有步行面。航拍树冠遮住了台阶上端，保留地图线位作为近似，暂不画接入庭院或门口的路线。它与周南桥出入口楼梯、挡门外横道是三个独立对象。

## 新斋楼体更新

- [荔知 2023 年斋区介绍](https://www.sohu.com/a/710071423_121117481)的有标名航拍可将聚翰斋、紫薇斋和红豆斋分别对应到同一组建筑，并观察到深色基座、首层开敞廊道、浅色墙垛和屋顶阵列。配合[校报的首层照片](https://www.sohu.com/a/747816124_121124028)，对楼侧内路一面的聚翰斋和紫薇斋绘制退后的玻璃、独立柱和贴地铺装。退深、柱距、材质和屋顶设备的具体尺寸采用照片近似。
- 场景标签把驿站、银行和信息中心标在所属楼栋，依据地址给出楼栋级位置。进入近景后能看到架空空间，门洞、营业厅与各服务的临街门头仍待定位。
- 新斋楼前庭院参考航拍可见的浅色铺装边线，铺装与地形和绿地分层。树冠及建筑阴影下的边界以原模型轮廓估计。学校[环校道说明](https://baowei.szu.edu.cn/info/1003/1381.htm)核对了聚翰斋与校医院在同一环路上的顺序，未标出驿站、银行或信息中心的门前接线。
