# 汇典楼入口与前场参考核查

核查日期：2026-11-07。范围仅包括南侧入口、两段前场台阶、两侧绿地及相邻边界，不对整座建筑作重新推断。

## 对照资料

- 深圳大学图书馆[官方平面布局](https://www.lib.szu.edu.cn/about/floor-plan)：[汇典楼一层图](https://www.lib.szu.edu.cn/sites/szulib/files/images/plan_1_2.png)画有前场两段台阶、两侧草坪、首层入口与两侧楼梯；[二层图](https://www.lib.szu.edu.cn/sites/szulib/files/images/plan_1_3.png)标出中央“正门 出入口”、前方平台及两侧楼梯。平面图是空间关系的依据，不带可供本次精确取数的比例或高程。
- [2018 年建筑分析](https://k.sina.cn/article_3914163006_e94d633e02700aybs.html?from=home)将首层入口前描述为灰空间，通向一层南大厅或二层；二层南侧为主入口和柱廊平台。文中图纸年代较早、内部功能可能变化，不等于现状施工图。
- [2022 年深圳发布转载的学校航拍](https://www.sohu.com/a/563224094_626425)标注汇典楼，可对照楼体、中央前场、草坪和左右邻楼的大致关系；本地观察图为 `build/campus-research-reference/huidian.jpg`。
- 本地观察照 `build/campus-research-reference/library-north.webp` 是带“知乎 @深大考研院”水印的正面图，具体拍摄日期和原始出处未核实；仅作为外观参考。
- 临时参考图保存在 `build/library-entry-reference/`，仅供核查，不作为程序纹理或运行资源。

## 可见关系与建模边界

1. 从前场向建筑依次是下段横向台阶、连续的矩形硬质铺装平台、上段横向台阶，再到建筑前的灰空间。两段之间在照片及官方一层示意图中均为可通行的完整地面；不应做成凹槽、断面或填满绿化的空隙。
2. 正面照中，上段台阶穿过两侧低矮石砌边界的中央开口；边界后是草坪和植物。靠近下段的进路两侧有修剪绿篱及低植被，植物并非沿整个石墙等高一致。2022 航拍可辨楼前对称草坪和中央铺装的总体关系，不能据此精确复原路缘。
3. 主体底部在柱后退让，形成开敞、有进深的一层灰空间；一层平面中央可见向内的门。建筑分析所述入口功能来自较早资料，不据此断言当前所有门的具体开放状态。
4. 两侧各有转折楼梯通到二层平台；官方一、二层平面图和旧南立面图显示楼梯的对称组织和平台关系。二层前方有宽平台，中央设正门，并向左右连廊方向延伸。前场两段中央台阶与这两组上二层的侧梯是不同构件；不应将中央台阶直接画成贯通二层平台的大台阶。
5. 本地照片和旧图中可见平台前缘的浅色水平墙体及绿色植物；遮挡使其精细构造、栏杆、入口门扇及当下材质不能可靠辨认。现有侧路只能作轮廓参照，照片不足以判定路面用途、精确宽度或路缘细部。

未核实：台阶级数、踏步宽高、两段间的深度、真实标高、挡墙结构及高度、铺装的材料和接缝、植物品种与数量，以及台阶和平台的精确尺寸。按视觉匹配时应保留这些限定，不能把屏幕量取或粗地形值称为实测。
