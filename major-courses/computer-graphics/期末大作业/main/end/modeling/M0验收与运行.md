日期：2026-11-06。状态：通过。由主 Agent 设计接口、审查实现并完成最终跨端和独立包验收；三个小范围实现使用 gpt-6.1-terra / max 子 Agent。

## 成果与范围

合成测试场景为一个带铰链门、透明裁切格栅和多层构件的亭架，**不是深大建筑复原**。64 个资产节点、58 个网格、5,870 个三角形；最长实际父子链为 6 层。输出包括可编辑 `.blend`、自包含 GLB、C++ 兼容资源、双端查看器、源代码和验收记录。

当前实现只验证 M0。没有替换校园中的任何地标，也没有将独立 C++ 查看器接入 `final-campus`；立德门、周南桥和通用 skill 分别属于 M1、M2、M3。

## 从项目根目录运行

首次配置或恢复环境：

```powershell
python -m venv build/modeling-pipeline/venv
build/modeling-pipeline/venv/Scripts/python.exe -m pip install -r tools/end/requirements-pipeline.lock.txt
npm --prefix main/end/modeling/viewer ci
```

构建与检查：

```powershell
build/modeling-pipeline/venv/Scripts/python.exe tools/end/pipeline.py doctor
build/modeling-pipeline/venv/Scripts/python.exe tools/end/pipeline.py probe-build
build/modeling-pipeline/venv/Scripts/python.exe tools/end/pipeline.py build pipeline-fixture
build/modeling-pipeline/venv/Scripts/python.exe tools/end/pipeline.py validate pipeline-fixture
build/modeling-pipeline/venv/Scripts/python.exe tools/end/pipeline.py preview pipeline-fixture
```

`preview` 保持一个仅绑定 127.0.0.1 的服务器，默认端口 4173；浏览器地址和实际目录会打印到终端。`--prepare-only` 只生成静态页面。根 `CMakePresets.json` 沿用本机课程编译器配置；`probe-build` 使用根 CMake 的专用模式，产物位于 `build/modeling-pipeline/cmake`，不复制其他实验资源。

查看 `build/modeling-pipeline/pipeline-fixture/latest.json` 获取刚生成的 run 目录。在另一个终端运行浏览器验收：

```text
node tools/end/verify_pipeline_browser.mjs "http://127.0.0.1:4173/?asset=/assets/pipeline-fixture/manifest.json" <run目录>
```

自动化默认使用本机 Edge 的独立进程，不附加个人浏览器；可通过 `PIPELINE_BROWSER` 指定另一个 Chromium 可执行文件。检查生成的 Web/原生多视角截图后，才执行：

```powershell
build/modeling-pipeline/venv/Scripts/python.exe tools/end/pipeline.py validate pipeline-fixture --visual-reviewed
build/modeling-pipeline/venv/Scripts/python.exe tools/end/pipeline.py package pipeline-fixture
build/modeling-pipeline/venv/Scripts/python.exe tools/end/test_pipeline.py
```

`--visual-reviewed` 是对已经完成的图像审查作记录，不能替代看图。接受状态绑定实际模型、原生程序、浏览器收到的字节、网页代码、报告和截图哈希。后续改变这些内容需要重新验收。

## 已知边界

- 此处的性能记录来自无头浏览器，不能当作全校园交互帧率结论。
- 旧格式出口表现基础色、纹理、透明裁切和基本光照；PBR 金属度、粗糙度、法线贴图等差异在转换报告中记录，两个渲染器不要求逐像素一致。
- Blender 导出同一纹理的颜色和透明通道时有 sampler 提示；已核对实际嵌入图像、透明裁切与兼容纹理像素。格式 Validator 没有报错或警告。
- 当前 schema 与验证器按 M0 夹具限定了层级、锚点和动件；迁移真实资产时需将非必需能力改为可选，不能强迫所有简单地块拥有门或四层结构。
- 现有全校园生成器与模型未被重构。独立资产接地、旧面替换和校园放置将由 M1 验证。
