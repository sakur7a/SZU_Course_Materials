模型状态为 `photo_based_approximation`，不是实测复原。输入照片不作为纹理分发。

- [深圳大学外国语学院校园风光](https://sfl.szu.edu.cn/xysh/xyfg.htm)，[原图](https://sfl.szu.edu.cn/images/XYFG/1-201112091426.jpg)：外侧照片可辨北侧双高墙与开口、南侧实墙、密集水平缝、低悬挑檐、竖排校名和蓝门牌。照片年代与当前状态存在差异。
- [2022 年校方航拍转载](https://www.thepaper.cn/newsDetail_forward_18845502)：用于观察双车道、中央分流岛和两侧岗亭的大致关系。临时帐篷等未作为永久建筑。
- [学校车辆门禁升级通知](https://baowei.szu.edu.cn/gzdt/5.htm)：门禁设备不能依据历史照片声称为当前状态。
- 原有 `main/end/code/data/gates-west.json` 和 `campus_gates_west.py` 给予校园中心 `(-410, -54)`、入口朝东和沿道路两侧的既有近似占地。它们是项目内模型尺度约束，不是测绘依据。

门墙及岗亭尺寸、厚度、窗格分隔、横缝间距、地面细节、门杆和蓝牌号码为照片及旧模型约束下的估计。两个门墙、岗亭与中央小岛按裁剪地形接地；裁剪地形本身为既有项目近似，并非实测。竖排“深圳大学”通过系统华文行楷字形重绘，不声称为原作书法；PNG 是生成输入，字体文件未复制。蓝牌 `3688` 沿用原项目示意，不能作为现状地址证据。模型内默认抬起的一根门杆仅供程序交互演示。

作者坐标为 Blender 米制 X 东、Y 北、Z 上；标准与兼容出口为 X 东、Y 上、Z 南。地形及道路上下文只用于采样和预览，不属于门体资产，也不能进入 GLB 与兼容网格。校园 placement 的海拔原点由上下文清单记录，不写入模型本体变换。
