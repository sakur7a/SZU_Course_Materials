# 体育场西北入口与道路连接

本轮完成的是西北可见开口及其相邻缺陷修复，不能据此称整座体育场的所有门与看台路线已完成。

## 依据与几何

校方航拍和已有卫星图支持西侧主看台北端存在看台间隙及铺面延伸；对应参考节点为 OSM `way/239872138` 末端 `(358.36,-477.02)`。具体配准、约5米开口、约4米铺面宽度和材质仍为模型估计。未添加没有证据的大门楼或门扇。详见 [来源记录](../code/data/stadium-entry-sources.md)。

局部裁切原看台底板、蓝座和边缘梁，接头约43.5平方米，从已有道路接到场内绿色通道。新增铺面按原道路和场面投影相减，没有覆盖跑道纹理，也没有替换公共道路。

实际画面另暴露了原 #0 与 #46 看台斜面约107.55平方米的交叉重叠。已在核对基线后移除重复折返片及配套蓝座/梁，保留有效邻段；补充西北外缘的贴地背面，墙顶依保留斜面收口。原照明杆未改，另补与原杆同截面的支承。新背面与支承是为闭合模型结构所作的估计，不作为现场构造的精确复原。

## 验收

- 主 Agent 独立重建，10个输出文件与候选哈希相同。
- 实际 C++ `TerrainHeights` / `WalkSurfaces` 对3路线、510点正反向检查通过；两端从实际地面起步，脚高容差5毫米，并断言每步升降不超过0.31米。实际最大脚高差约0.000008米，为数值对照误差而非测绘精度。
- 使用隔离副本把入口行走网格移至远处，实际 C++ 检查按几何错误拒绝，证明不能只靠下方地形兜底通过。
- 新铺面与原可见路面/场面没有实质投影重叠，接缝高差为浮点误差量级；3.2米宽抽样带无缺面或埋地。
- 子 Agent 以0.35米半径、脚上0.05–1.8米的保守体积检查保留看台、背面、路缘、膜棚、灯杆等，510点无疑似相交；这不等于完整物理系统。
- 主 Agent 查看了实际隐藏 OpenGL 窗口产生的场内、场外和俯视图；修正了原有尖片及看台下方的绿色透视问题。
- 元平5路线回归、程序自检和 `verify_scene_data.py` 全场资源检查通过。发布目录再次执行3组检查，并核对资源与源码哈希。

本轮仅更改3个既有看台网格及总计数，新增7个本地资源；其余699个既有资源保持不变。
