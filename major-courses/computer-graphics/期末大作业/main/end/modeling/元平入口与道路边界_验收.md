# 元平体育馆入口与道路边界

本轮按用户要求优先完善建筑外观和入口边界，通用 skill 封装后置。

## 已完成

- 两翼外梯由内侧低处向外侧上升，各26级，接入二层平台。
- 切开两翼原实墙中的估计入口，增加退后的玻璃、门框、门槛和到门前的连续踏面；不建造或宣称完成馆内空间。
- 保留中央浅阶，补足其与低层门口之间的平台。
- 增加门前灰色矩形铺块、两侧落脚过渡和随地形下伸的基础；不改变映射道路或其共享前场的原有表达。
- 重新处理平台端部栏杆，保留屋檐桁架、浮雕、馆名和相邻北夏馆资源。
- 独立行走网格接入实际 `WalkSurfaces`，没有把屋顶或整座楼壳作为可走层。

参考照片能支持两翼外梯、中央宽浅台阶和灰色前场铺块；用户确认可由楼梯上二楼。具体二层门洞、梯顶连接、26级数量、尺寸和高程仍为建模估计。详见 [参考依据](../code/data/yuanping-entry-sources.md)。

## 实际验收

主 Agent 独立重新执行生成模块，与子 Agent 候选的10个输出文件哈希逐一相同。源资产仅更改元平的 base、shell、truss、glass、steps 五个网格及 `campus-data.json` 中的对应计数，新增 walk、paving、纹理和两份路线数据；其余692个既有资源保持不变（含此前立德门独立包）。

五条路线共827个采样点，在实际 C++ 相机使用的 `TerrainHeights` 和 `WalkSurfaces` 上正反向检查，10个方向均通过。最大预期脚高误差约0.00005米，单次抬升不超过约0.1643米；这是模型数值检查，不是实际校园测量精度。独立的高层路线从其平台高度起步，不声称能从地面直接跳到二层。

已检查实际 OpenGL 正面、两翼楼梯、低层入口和二层门槛图片；没有再次操作用户桌面。原程序自检、`verify_scene_data.py` 全场资源检查及发布目录再运行均通过。用户停止 Computer Use 后没有继续发送窗口输入。

局限：未实现完整墙面碰撞，未测量真实尺寸，未确认当前门禁开放状态，也没有验证其他建筑的所有入口。完整校园生成器已加入局部后处理调用，回调和同目录模式已测试，但本轮没有重新生成整个校园。

本机复现环境为 `C:/Users/ooo/AppData/Local/Programs/Python/Python312/python.exe`，`PYTHONPATH` 指向项目的 `build/campus-python`，版本为 NumPy 2.5.4、Shapely 2.0.7、mapbox-earcut 1.0.3、Pillow 12.3.0。用 `PYTHONDONTWRITEBYTECODE=1` 避免源目录缓存；测试图、缓存和回调临时目录不属于正式资源。

```powershell
$env:PYTHONPATH = Join-Path (Get-Location).Path 'build/campus-python'
$env:PYTHONDONTWRITEBYTECODE = '1'
& 'C:/Users/ooo/AppData/Local/Programs/Python/Python312/python.exe' main/end/code/campus_yuanping_entry.py --output build/yuanping-entry-candidate/assets
cmake --build build --target final-campus -j 4
build/bin/final-campus/final-campus.exe --yuanping-walk-check
```

候选输出需经过比较和核验后同步到源码 assets，不能把生成命令与正式发布混为一步。
